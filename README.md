Student Performance Analyzer

Project Overview

The Student Performance Analyzer is a Python-based project designed to analyze students’ academic performance and provide useful study feedback.

The program processes subject scores, calculates the student’s overall average, identifies academic strengths and weaknesses, and uses a machine learning classification model to categorize overall performance.

Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Machine Learning
* Google Colab

Features

* Enter and analyze student scores
* Calculate the overall average
* Identify strongest and weakest subjects
* Classify overall student performance
* Provide targeted study feedback
* Display clear performance results

Machine Learning

The project includes a machine learning classification component that uses students’ performance data to predict an overall performance category.
